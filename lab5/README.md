# Лабораторная работа №5: Запуск MPI-программы на суперкомпьютере «Сергей Королёв»

**Студент:** Родионов Антон  


## 1. Цель работы
Запустить параллельную программу перемножения матриц (MPI) на вычислительном кластере суперкомпьютера «Сергей Королёв». Исследовать масштабируемость алгоритма при увеличении количества вычислительных ядер (потоков) и размера задачи в условиях высокопроизводительной среды.

## 2. Описание среды выполнения

Работа выполнялась на суперкомпьютере **«Сергей Королёв»**.

**Особенности архитектуры:**
*   **Многоядерные узлы:** Каждый вычислительный узел оснащен мощными многоядерными процессорами (Intel Xeon / AMD EPYC).
*   **Высокоскоростная сеть:** Взаимодействие между процессами осуществляется через сеть InfiniBand, что обеспечивает минимальные задержки при передаче сообщений MPI.
*   **Планировщик задач:** SLURM. Запуск производился через скрипт задания, распределяющий процессы по ядрам одного или нескольких узлов.
